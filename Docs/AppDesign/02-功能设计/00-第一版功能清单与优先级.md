# 第一版功能清单与优先级

## P0

| 模块 | 目的 | 验收 |
|---|---|---|
| 情侣绑定 | 建立私密空间 | 邀请加入，可解绑 |
| 关系状态 | 降低表达门槛 | 状态生成关系线索 |
| 轻触回应 | 低成本连接 | 有动效、震动和状态反馈 |
| 互动任务 | 促成具体行动 | 发起、接收、完成、跳过完整 |
| DeepTalk | 异步深度沟通 | 双方回答后互相解锁 |
| 通知触达 | 把互动带回日常 | 免打扰、去重、可行动 |
| 共同记忆 | 沉淀关系资产 | 双方确认后保存、删除 |
| 同步与隐私 | 保证双端一致 | 权限、删除、弱网明确 |

## P1

共同空间、宠物状态、主题包、语音回应、愿望清单、AI 推荐、表达润色、纪念日和基础会员。

## P2

多宠物、多房间、活动、小组件、跨语言和复杂共同计划。

## 首个垂直切片

情侣绑定 → A 选择想被听见 → B 收到提示 → B 发送我在，等你想说 → 推荐 1 分钟问题 → 双方完成 → 保存记忆。
