# 互动反馈与动效规范

## 规格

| 交互 | 动效 | 触感 |
|---|---|---|
| 轻触回应 | 图标放大 1.1 倍后回弹 | 约 40ms |
| 长按拥抱 | 进度环填充后发送 | 约 80ms |
| 摇一摇问题 | 卡片翻转 | 80ms × 2 |
| 收到回应 | 顶部提示条下滑约 200ms | 可选 |
| 完成任务 | 双方头像连线、结果淡入 | 可选 |
| 保存记忆 | 卡片进入时间线 | 无需震动 |

重要但不紧急用底部弹窗，不用全屏强打断；提供现在完成和稍后提醒。关键控件有 normal、pressed、loading、success、disabled、error、offline 状态。支持关闭震动和减少动效。

## 关系动作

关系动作是低成本的亲密表达，不要求接收方继续回复，也不等同于普通 Emoji。

首版固定六个动作：

| 动作 | 语义 | 默认使用场景 |
|---|---|---|
| 拥抱 | 安抚、想念、我在这里 | 想被听见、能量低、暂时不方便 |
| 亲亲 | 表达亲密 | 日常聊天、完成互动 |
| 牵手 | 陪伴、一起面对 | 讨论困难、异地 |
| 拍拍 | 辛苦了、别太累 | 工作或学习压力 |
| 想你 | 表达思念 | 无法及时聊天 |
| 早安／晚安 | 日常仪式 | 每日开始或结束 |

拥抱是默认主动作，状态卡和关系事件优先展示 送一个拥抱。

发送规则：

- 一次点击即可发送；
- 发送后 3 秒内可以撤回；
- 前台显示短暂动画，可选轻震动；
- 后台通知使用TA 给了你一个拥抱等具体文案；
- 接收方可以回送同一动作，但不形成强制往返；
- 互动记录按天聚合，不逐条堆积轻触动作；
- 首版不开放情侣自定义动作，避免语义和表现不一致。
