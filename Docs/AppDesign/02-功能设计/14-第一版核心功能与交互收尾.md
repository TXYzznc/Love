# 第一版核心功能与交互收尾

> 用途：作为第一版原型和开发切片的收尾清单。未列入 P0 的功能暂不进入首个可用版本。

## P0 核心闭环

1. 情侣绑定与私密关系空间；
2. 关系收件箱和类型化会话列表；
3. 关系状态：一个回应需求 + 一个当前状态 + 可选补充文字；
4. 需求型状态由伴侣真人回应；
5. 播报型状态可由 AI 宠物问一个具体开放问题；
6. 用户真人回答后生成伴侣可见事件；
7. 快捷关系动作：拥抱、亲亲、牵手、拍拍、想你、早安／晚安；
8. 塔罗、抽签等事件完成后可升级为主题会话；
9. 活跃会话、待回应、固定、静音和自动归档；
10. 互动记录与共同记忆分离；
11. 共同记忆需双方确认；
12. 基础宠物／共同空间反馈；
13. 通知、免打扰、弱网草稿和删除权限。

## 首个可玩切片

绑定 → 发布“想被陪着 + 心里有点乱” → 伴侣看到关系线索 → 发送一个拥抱 → 可选进入 1 分钟主题 → 双方完成 → 保存互动记录 → 双方确认后改变共同空间。

第二条切片：

发布“今天能量低” → AI 宠物问一个开放问题 → 用户真人回答 → 伴侣收到事件 → 进入主题会话 → 伴侣用真人文字或关系动作回应。

## 状态生命周期

草稿 → 已发布 → 等待回应 → 已查看 → 已回应 → 已完成 → 已过期或已收回。

播报型状态增加：

已发布 → AI 询问一次 → 用户回答或跳过 → 生成伴侣事件。

默认不显示未回应倒计时，不使用红点和负面文案制造压力。发布者可以选择一次温和提醒，系统不自动连续催促。

## 交互规格

| 交互 | 首版行为 |
|---|---|
| 发送拥抱 | 一次点击发送，3 秒内可撤回 |
| 关系动作 | 前台动画，可选约 40ms 震动 |
| 长按拥抱 | 约 80ms 震动，松手发送 |
| 摇一摇抽签 | 80ms × 2 震动，问题卡片翻转 |
| 收到关系事件 | 顶部提示条或收件箱待回应卡 |
| 主题完成 | 显示完成状态，提供继续聊和保存记忆 |
| 保存记忆 | 双方确认后卡片进入共同记忆 |
| 弱网 | 保留草稿，恢复后同步 |

所有关键控件需要 normal、pressed、loading、success、disabled、error、offline 状态，并支持关闭震动和减少动效。

## 第一版验收标准

- 用户能在 5 秒内理解首页下一步可以做什么；
- 状态发布后，伴侣知道应该如何回应；
- AI 不会替伴侣回应需求型状态；
- AI 询问后必须由真人回答；
- 普通聊天、事件和主题会话不会混在同一条历史里；
- 互动记录能回到原始事件或主题窗口；
- 共同记忆不会未经双方确认自动写入；
- 一方低频或暂时不回应时，不产生惩罚和关系评分；
- 解绑、删除、隐藏原文和关闭通知均可完成。

## 暂缓到 P1

- 复杂小游戏合集；
- 自定义关系动作；
- 多宠物和多房间；
- AI 自动生成完整任务；
- 关系趋势图；
- 公开社区；
- 复杂会员和经济系统；
- 自动从普通聊天批量提取记忆。
