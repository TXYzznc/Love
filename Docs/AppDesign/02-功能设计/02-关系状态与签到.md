# 关系状态与签到

## 目标

不用写长消息，也能让伴侣知道我现在需要什么。

## 状态

| 状态 | 默认回应 |
|---|---|
| 想被听见 | 我在，慢慢说 |
| 想要抱抱 | 发送拥抱 |
| 想要建议 | 要不要一起想办法 |
| 想安静一下 | 好的，我在这里 |
| 想分享 | 发起轻量分享 |
| 今天能量低 | 提供 30 秒回应 |

状态生成关系线索，可设置有效期、是否提醒和是否保存历史。允许撤回和修改，过期后归档。不转成情绪分数，不显示等待时间和积极度。

状态发布时区分“需要回应”和“状态播报”。前者必须由伴侣真人回应；后者可以在用户同意后由 AI 宠物询问一次，再把真人回答交给伴侣查看。
