# 产品与体验总纲 v0.1

> 更新：2026-10-11。当前处于前期产品设计阶段。

## 一句话

一款帮助情侣表达状态、完成有意义互动并沉淀共同记忆的关系维护 App。

它不替代微信聊天，解决的是想靠近但不知道怎么开始、如何回应、怎样长期坚持。

## 核心定位

> 微信负责日常聊天，本产品负责让情侣更容易靠近、理解和持续经营关系。

宠物、共同空间、小游戏和动画是参与入口与反馈层，最终价值是促成真实的双人互动。

## 体验支柱

1. 有方向的表达：把我想被理解转为状态信号。
2. 低压力的回应：提供具体、可跳过的回应方式。
3. 共同完成：优先设计双方共同参与。
4. 从互动到记忆：重要内容需双方确认后保存。
5. 少打扰，多帮助：通知只提示可行动的关系线索。
6. 合作而非考核：不比较谁主动，不给关系打分。

## 差异化闭环

状态选择 → 生成关系线索 → 伴侣轻触回应或进入任务 → 匹配互动 → 完成连接 → 双方确认并沉淀记忆。

## 第一版边界

必须成立：情侣绑定、状态、轻触回应、互动任务、DeepTalk、通知、共同记忆、基础空间反馈、同步和隐私。

暂不做：公开社区、关系评分、位置监控、复杂农场、强制连续打卡、AI 自由生成资产、自动判断出轨或分手。

## 指标假设

关注第一次双人互动、首周 2～3 次有回应的互动、记忆保存率和低频一方的参与感。
