# 关系成长循环 v0.1

## 主循环

进入 App → 查看关系脉搏 → 选择状态或回应伴侣 → 完成轻任务／DeepTalk／现实行动 → 即时反馈 → 双方确认是否保存记忆 → 共同空间变化 → 下次基于历史和当前状态推荐。

## 参与层级

| 层级 | 时长 | 例子 |
|---|---:|---|
| 轻触回应 | 5～30 秒 | 拥抱、倾听、感谢 |
| 互动任务 | 1～10 分钟 | 问题卡、共同选择 |
| DeepTalk | 5～20 分钟 | 双方回答和追问 |
| 现实行动 | 10 分钟以上 | 通话、见面、愿望 |

## 关系脉搏

不是关系分数，只呈现当前状态、未完成回应、最近互动、下一步和可回看的记忆。

## 中断规则

可跳过、暂停、换题和稍后继续；不扣资源、不惩罚宠物、不显示关系负债。断网保留草稿，恢复后同步。

## 长期成长

内容、空间和记忆越来越具有只属于你们的特征，而不是关系数值上涨。
