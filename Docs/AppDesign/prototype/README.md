# HTML 交互原型

这是《两个人的关系空间》第一版可点击原型，用来验证关系收件箱、状态表达、关系动作、AI 一次询问、塔罗事件和互动记录的结构。

## 打开方式

直接用浏览器打开 `index.html` 即可。原型不依赖构建工具和外部网络资源，交互状态会保存在浏览器 `localStorage`。

## 已覆盖的体验路径

1. **需求型状态**：发布状态 → 对方事件 → 发送一个拥抱 → 可进入独立主题会话。
2. **播报型状态**：打开小兔助手 → 回答一个具体问题 → 生成对方可见的关系事件。
3. **塔罗／抽签事件**：对方发起“帮我摇一摇” → 摇出结果 → 升级成主题会话。
4. **互动记录**：状态回应、关系动作、主题和事件可以回到原始窗口；普通聊天不混入记录。
5. **共同空间**：互动完成后反馈到宠物、小屋和下一件空间变化。

## 原型范围

本版用于确认信息架构、会话分型和关键交互，不包含真实账号、推送、传感器、后端同步、完整小游戏合集和支付能力。
